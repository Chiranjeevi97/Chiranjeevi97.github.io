Privacy policy

Morning Assistant · Last updated November 2, 2026

Morning Assistant is a personal application used only by its owner. This policy explains what Google data it accesses and how that data is handled.

Data it accesses

  • Gmail: reads messages to find emails that need attention, and creates draft replies. It cannot send email.
  • Google Calendar: reads events for the current day.
  • Google Tasks: reads tasks that are due.

How the data is used

Data is used only to produce the owner’s daily brief. It is processed on the owner’s own computer, including by a locally run language model. Email content is not sent to any third-party AI service.

Sharing

Google user data is never sold, shared with third parties, used for advertising, or used to train AI models. The brief is delivered only to the owner’s private Slack workspace.

Storage and retention

Access tokens and short-lived working data are stored on the owner’s computer with restricted file permissions. Working data is deleted on a rolling basis and is not backed up to external services.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Morning Assistant’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be raised through GitHub.
